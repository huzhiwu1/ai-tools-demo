# 需求访谈记录

## 项目背景

用户希望创建一个 AI Agent，能够根据自然语言描述自动生成 Coze 平台的工作流。

## 核心需求

1. 接收用户自然语言需求
2. 由 LLM 规划工作流草图
3. 生成 Coze 工作流节点 JSON
4. 通过 MCP 调用内部 Coze 接口创建 / 保存 / 试运行工作流
5. 后续扩展成可修复已有工作流的 Agent

## 技术约束

- 语言：TypeScript
- AI 框架：LangChain + LangGraph
- 前端：React
- 架构：前后端分离，monorepo

## 关键设计决策

1. **Agent 与工具分离**：Agent 负责编排，工具层封装 Coze API
2. **Prompt 独立管理**：便于调整和 A/B 测试
3. **模板优先**：先用模板生成基础结构，再用 LLM 填充细节
4. **本地校验**：在调用 Coze API 前先本地校验，减少无效调用
5. **修复闭环**：校验失败时自动修复，而非直接报错

## 后续扩展方向

- 支持多 Agent 协作（Supervisor 模式）
- 支持工作流模板库
- 支持工作流版本管理
- 支持工作流执行历史分析
